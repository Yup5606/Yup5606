## About

중학교 시절부터 미술을 전공하며 시각적 사고력을 길러왔습니다.

현재는 웹디자인과 UI/UX를 공부하며 단순히 보기 좋은 화면이 아닌,
사용자의 경험을 고려한 디자인을 만들기 위해 노력하고 있습니다.

디자인부터 퍼블리싱까지 직접 구현하며
아이디어를 실제 서비스로 완성하는 과정에 가장 큰 즐거움을 느낍니다.
